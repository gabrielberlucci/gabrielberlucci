### Projetos em Destaque

#### [Trace - Mini ERP](https://github.com/gabrielberlucci/trace)

Sistema Full-Stack para gerenciamento de um varejo (vendas, produtos, clientes e fornecedores etc).

- **Tecnologias:** TypeScript, Node.js, Express.js , PostgreSQL, Prisma ORM, Redis, BullMQ, React.
- **Features:**
  - CRUD completo com autenticação JWT;
  - Processamento assíncrono de XML via filas (BullMQ + Redis), com planejamento futuro de importar toda a nota, não só o estoque;
  - Modelagem de banco de dados;
  - Paginação nas listagens da API;
  - ZOD V4 para validação de dados.

#### [Node Task Manager](https://github.com/gabrielberlucci/node-task-manager)

Uma aplicação inspirada no Task Manager do Windows. Realiza a coleta de métricas e informações de hardware.

- **Tecnologias:** TypeScript, Node.js, Express.js, Powershell
- **Features:**
  - Coleta de informações estáticas de CPU, Memória RAM;
  - Coleta de informações de processos;
  - Uso de SSE para envio de informações variáveis(processos, uso de CPU/RAM, uptime).
